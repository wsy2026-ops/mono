MONO 社区 · 内网穿透使用说明（cpolar 免费版）
===============================================================

用途：让不在同一 WiFi 的朋友（手机 4G/5G、家里、学校）也能
      访问你的 MONO 社区。原理：cpolar 在你电脑和它的服务器
      之间建立一条隧道，朋友访问公网地址，数据自动转发到你
      电脑的 5000 端口。

--------------------------------------------------------------
【第 1 步：启动 MONO 社区（必须先启动）】
--------------------------------------------------------------
1. 双击「一键启动.cmd」，看到"已启动"即可，保持窗口开着
2. 本机先测试：浏览器打开 http://127.0.0.1:5000 能进就对了

--------------------------------------------------------------
【第 2 步：安装 cpolar（只装一次）】
--------------------------------------------------------------
1. 用浏览器打开官网：https://www.cpolar.com
2. 点「免费使用」注册一个账号（邮箱注册即可，免费）
3. 登录后下载 Windows 版安装包
   （test6 文件夹里已放了一份：cpolar-setup-win64.zip，
    解压后双击里面的安装程序即可，一路默认下一步）
4. 安装完成后，桌面/托盘会出现 cpolar 图标

--------------------------------------------------------------
【第 3 步：登录并创建隧道（每次启动后需要点一下）】
--------------------------------------------------------------
1. 浏览器打开：http://localhost:9200 （cpolar 本地管理页面）
2. 用刚才注册的账号登录
3. 左侧菜单：隧道管理 → 创建隧道，按下面填：
     隧道名称：  mono（随便填，别重复）
     协议：      http
     本地地址：  127.0.0.1:5000
     域名类型：  随机域名
     地区：      China Top
4. 点「创建」
5. 左侧菜单：状态 → 在线隧道列表，能看到一条公网地址
   （形如 https://xxxxxx.cpolar.top）

--------------------------------------------------------------
【第 4 步：把地址发给朋友】
--------------------------------------------------------------
1. 复制在线隧道列表里的公网地址（https://xxxxxx.cpolar.top）
2. 发给朋友，他们浏览器打开就能访问你的社区了
   （手机用 4G/5G 流量访问也完全没问题）

--------------------------------------------------------------
【注意事项 / 常见问题】
--------------------------------------------------------------
1. 免费版公网地址是随机的，24 小时左右会变一次，变了重新
   去「在线隧道列表」复制新地址即可（隧道不用重新创建）
2. 电脑关机 / 一键启动关了，穿透就断了；下次开机重开服务后，
   隧道通常会自动恢复（cpolar 常驻后台），地址也可能变化
3. 想固定地址（不变、好看）：cpolar 有付费套餐（基础套餐起），
   在「预留」里保留二级子域名，创建隧道时选「二级子域名」
4. 速度：免费版带宽有限，图片/视频会有点慢，聊天打字完全够用
5. 安全提醒：穿透后任何人都可能打开你给的地址，请务必：
   - 管理员账号用强密码，定期改
   - 敏感词、举报机制保持开启
   - 只把地址发给信得过的人，别到处公开
6. 如果学校电脑（Win7）装不了：下载 32 位版
   （https://www.cpolar.com/static/downloads/releases/3.3.12/
    cpolar-stable-windows-386-setup.zip），
   或换用 natapp（https://natapp.cn，同样免费）
7. 穿透不影响局域网：局域网内继续用 http://你的IP:5000，
   外面的人用 cpolar 公网地址，两者互不影响

--------------------------------------------------------------
【一句话回顾】
--------------------------------------------------------------
先开「一键启动.cmd」→ 浏览器开 localhost:9200 登录 →
创建隧道（本地地址 127.0.0.1:5000）→ 复制公网地址发朋友。
