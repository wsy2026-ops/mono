# 10 · 注册与登录

## 一句话
用户名 + 密码 + 滑块验证即可注册；支持邮箱验证码和 GitHub 登录。

## 注册
- 入口：站点右上角「注册」
- 必填：用户名（2-16 字，可用中文/字母/数字/下划线，不能与现有用户重名）、密码（至少 6 位）
- 人机验证：注册和登录都有滑块验证，防止机器批量注册
- 注册成功后自动登录，赠送新用户初始积分

## 登录方式（三种）
1. 用户名 + 密码
2. 邮箱验证码：需要先在「个人设置 → 账号安全」绑定邮箱；忘记密码时也走这条路重置
3. GitHub 授权登录：登录页点 GitHub 图标，授权后自动绑定/注册（首次会要求设用户名）

## 邮箱
- 绑定路径：个人设置 → 账号安全 → 绑定邮箱
- 用途：验证码登录、找回密码、接收重要通知（暂不支持邮件订阅）
- 收不到验证码：先看垃圾箱；60 秒内只能发一次，别连点

## 修改资料
- 头像：个人设置里上传（jpg/png/gif，过大的图会自动压缩）
- 用户名：个人设置里改，**改名消耗积分**，且不能与现有用户重名
- 个性签名：个人设置里改，会显示在主页和帖子里
- 密码：个人设置 → 账号安全 → 修改密码（需要知道当前密码）

## 账号安全
- 账号无法注销，但可以联系管理员冻结
- 连续输错密码不会锁账号，但会有频率限制
- 如果账号被盗，用绑定邮箱重置密码，并联系管理员
