# 44 · 卡题排错指南

## 一句话
按状态码对症下药，别再对着代码发呆了。

## CE 编译错误
- 看编译器输出第一条错误（后面的多是连锁反应）
- C++ 高频：缺 include、拼写、分号、用了不存在的方法
- Python 高频：缩进、用了不存在的库

## WA 答案错误
1. **手算样例**：样例都过不了 → 读错题或输出格式错
2. **对拍**：写个暴力解，随机小数据对比，定位分歧点
3. **想边界**：空输入、N=1、最大值、重复值、负数
4. **看输出格式**：大小写、空格、换行、末尾空行——WA 里格式错占一半

## TLE 超时
1. 先算数据范围：N=10⁵ 就不能 O(n²)
2. 找隐藏的慢点：循环里字符串拼接、重复计算、没开快速 IO（C++ 用 `ios::sync_with_stdio(false)`）
3. Python 卡常：换 PyPy、优化常数、减少函数调用

## MLE 超内存
- 数组维度是否开错（全局 10⁷ 个 int 就 40MB）
- 递归深度太深爆栈 → 改迭代或开栈空间

## RE 运行错误
- 数组越界（最常见）：检查下标范围和边界条件
- 除零：检查分母
- 递归爆栈：加深栈或改非递归
