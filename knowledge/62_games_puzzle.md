# 62 · 汉诺塔 / 华容道 / 数独

## 一句话
三款纯推理益智游戏，比步数比时间。

## 汉诺塔
- 把圆盘从 A 柱全移到 C 柱：每次一个盘、大盘不能压小盘
- 比的是**步数**（最优步数是 2ⁿ-1，4 盘 15 步、5 盘 31 步）
- 阶数越高分越多，挑战 8 阶以上

## 华容道
- 滑块解谜：把目标块移出出口
- 三种规格：4×4 / 5×5 / 6×6
- 比步数/时间，步数越少分越高

## 数独
- 标准 9×9：每行每列每宫 1-9 不重复
- 难度分级（简单/中等/困难），自动校验冲突
- 完成按用时给分

## 通用技巧
- 汉诺塔：递归思想，n 盘 = n-1 盘到辅助柱 + 最大盘到底 + n-1 盘跟上
- 数独：先扫唯一候选数，再区块排除
- 都支持触屏，手机上能玩
