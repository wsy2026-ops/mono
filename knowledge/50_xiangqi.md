# 50 · 中国象棋大师

## 一句话
比传统象棋多了「技能棋子」的魔改象棋：天梯匹配、赛季段位、抽签布阵。

## 入口
- /games → 中国象棋大师
- 首次进入有新手引导（重点讲和传统象棋的差异）

## 玩法
1. **匹配**：点「开始匹配」进队列，系统按积分（rating）匹配**真人对手**——匹配快慢看当时在线人数，凌晨可能等得久
2. **对战**：基础走子规则同传统象棋，但部分棋子带**技能**（如车的冲锋、炮的隔子打击）——悬停棋子看技能说明
3. **胜负**：吃掉对方将/帅即胜；超时判负；可认输/求和
4. **抽签**：部分模式随机棋子组合，考验应变

## 和「中国象棋（房间对战）」的区别
- **象棋大师**：天梯匹配 + 赛季 + 技能棋子（本站特色魔改）
- **中国象棋**：房间对战 + 随机匹配 + 残局闯关（传统规则）
- 问「象棋」时两边都可以指，看你想玩哪种

## 常见问题
**Q：匹配半天匹配不到？** A：真人对战需要对面有人。人少时段建议去「中国象棋」的匹配房下快棋，或去论坛水一贴等等。

**Q：技能看不懂？** A：对局里悬停棋子有说明；新手引导再看一遍。
