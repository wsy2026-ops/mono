# 中国象棋大师 · UI / 界面重构规划

> 目标：从「能玩的网页」做到「看起来像能上架的游戏」。
> 本文基于当前线上版本 v1.9.10 的实测，不是凭空规划。

---

## 一、现状盘点（实测数据）

### 页面与流程
| 页面 | 路由 | 状态 |
|---|---|---|
| 首页 | `/game/xqmaster` | 两栏：左侧阵容半盘预览 + 右侧标题/按钮 |
| 匹配 | `/game/xqmaster/match` | 三层旋转环 + 文字 + 取消 |
| 对局 | `/game/xqmaster/battle/<gid>` | 棋盘 + 右侧 3 面板 + 上下双方血条 |
| 结算 | `/game/xqmaster/result/<gid>` | 胜负大字 + 7 格数据 |
| 积分榜 | `/game/xqmaster/rank` | 统计格 + 排行表 |
| 图鉴 | `/game/xqmaster/codex` | 详情 + 单棋盘双标签演示 + 底部棋子栏 |
| 阵容 | `/game/xqmaster/lineup` | 编辑布阵 |

### 后端能力（已具备，不用重做）
- 数据表：`xqm_games` / `xqm_queue` / `xqm_rating` / `xqm_lineup` / `xqm_shards` / `xqm_wallet`
- 对局记录 `events` 已包含 `move` / `attack` / `dmg` / `kill` / `turn` / `over`，**战报和复盘可以直接用，不需要改后端**
- 服务端已有单方 150 秒超时判负、连续 10 回合无伤害判和、棋盘翻转（执黑视角）

### 视觉资产（现有亮点，重构时要保住）
- 棋子血量用**程序化裂纹**表达（五处裂纹源 + 崩口多边形），不是简单换色
- 特效：刀光（含沿途火星）+ 爆裂环 + 震屏 + 碎片抛射 + 伤害数字 + 命中闪白 + 裂纹升级
- 面板跟随站点 5 套主题（明暗 / 羊皮纸 / 海洋），棋盘固定木纹不跟主题

### 实测尺寸（1440×1600 视口）
```
视口          innerW = 1418
内容容器      229..1189  宽 960（居中，正常）
棋盘          311..799   宽 488   ← 格子 50px，棋子 42px
右栏          897..1189  宽 292
对局内容高度  ≈ 600px
```
**问题一目了然：视口 1600px 高，对局内容只占了 600px，下面 60% 是空的；棋盘作为主角只有 488px 宽。**

## 二、差距清单（按严重度分级）

### P0 —— 不做就不像成品
1. **对局页不撑屏**：棋盘是主角，却只占视口宽度的 34%、高度的 37%，大片留白
2. **没有战报**：右侧「战报」面板已被移除，玩家不知道刚才发生了什么
3. **没有回合计时**：服务端 150 秒判负，界面上完全看不到倒计时，玩家会莫名其妙被判负
4. **没有音效**：全站静音，操作没有反馈，手感像 PPT
5. **没有新手引导**：新玩家看到 32 个带血条的棋子，完全不知道「坐镇 / 护主 / 守垒 / 踏营 / 死战」是什么
6. **没有「轮到你了」提示**：对手回合时界面没有明显变化，玩家容易发呆

### P1 —— 影响手感与完成度
7. 无上一步标记、无棋谱坐标、无被吃棋子展示
8. 匹配页只有转圈 + 文字，没有「找到对手」的揭晓感
9. 结算页是干巴巴的数字，碎片 / 遗注奖励没有任何开箱演出
10. 加载态是「加载中…」纯文字，没有骨架屏；空状态也没有设计
11. 手机竖屏棋盘仅 297px，且没有横屏对局模式

### P2 —— 锦上添花
12. 没有设置页（棋盘主题、音效开关、动画速度、认输二次确认）
13. 无键盘操作 / 无障碍支持
14. 无复盘、无观战
15. 动画在低端机上没有降级策略

## 三、三阶段规划

### 阶段一：地基 + 对局核心（棋盘是主角）

**目标：把对局页做到可以直接截图当宣传图。**

**1.1 设计规范落地**
- 间距统一到 4 / 8 / 12 / 16 / 24 / 32 六档，去掉现有的零散数值
- 字阶收敛：11 / 12.5 / 15 / 18 / 24 / 32
- 色板：保留 `--xqm-*` 国风主色，补齐中性色阶（背景 / 边框 / 次要文字三级）
- 统一圆角（8 / 12 / 18）与阴影（卡片 / 浮层 / 聚焦三档）
- 动效时长统一到 120 / 180 / 260 / 420ms 四档，缓动曲线固定两种

**1.2 对局页改成「应用式撑满布局」**
- 容器改用 `100dvh`，纵向三段：顶部信息条 / 棋盘区（`1fr`）/ 底部操作区
- 棋盘尺寸由**可用空间反推**，不再写死 `--cw:50px`：
  - 取 `min(可用宽 ÷ 9, 可用高 ÷ 10.6)` 得到格子边长
  - 用 JS 算好写进 CSS 变量（`cellCenter()` 依赖真实布局，必须让 DOM 尺寸和变量一致）
- 三套断点：
  - 桌面（≥1100）：棋盘居中，右栏 320px 承载战报 / 计时 / 选中信息
  - 手机竖屏（<900）：棋盘占满宽度，信息折叠进底部抽屉，点击展开
  - 手机横屏：左右布局，棋盘占满高度，右栏压缩到 240px

**1.3 信息层补齐**
- **战报**：按时间倒序，分类着色（走子 / 攻击 / 特性触发 / 阵亡），最多保留 40 条
- **回合计时环**：环绕当前行动方的头像，最后 30 秒变红并脉冲
- **上一步标记**：起点画空心圈、终点画实心圈，中间虚线连接
- **双方对抗条**：把现在的上下两条血量条合并成一条横向对抗条（左红右黑），一眼看出优劣
- **被吃棋子托盘**：双方各一排小棋子（直径 20px），阵亡后飞入托盘

**1.4 交互反馈增强**
- 选中棋子后，可攻击目标上直接显示「预计 -36」伤害预览
- 特性触发时在棋子旁弹出短标签（如「锐气 +50%」）
- 行动点不足 / 不是你的回合 / 非法落点，都有明确的位置化提示（不只是顶部 toast）

**1.5 无障碍基线**
- 键盘：方向键移动光标、回车确认、Esc 取消
- `aria-live` 播报「轮到红方」「帅受到 42 点伤害」
- 可走 / 可打不只靠颜色区分，补上形状差异（实心 / 斜纹 / 描边）

**阶段一验收**
- 在 1440×900、1920×1080、iPhone SE 竖屏、iPhone 横屏四种尺寸下，棋盘都占满可用空间且不裁切
- 全程无横向滚动条
- 特效定位（`cellCenter`）在新布局下仍然准确

### 阶段二：全流程 + 音画反馈（让它「活」起来）

**2.1 音效系统**
- 音效清单：走子、落子、攻击挥出、命中、受击、阵亡、回合切换、倒计时警告、胜利、失败、按钮点击、错误
- 统一音量总线 + 音效开关 + 背景音乐开关
- 移动端首次用户交互时解锁音频上下文
- 来源优先 CC0 / 可商用素材，逐个确认授权

**2.2 首页重做**
- 保留阵容半盘预览，补充战绩卡片（积分 / 胜率 / 最近 5 局）
- 加「今日任务 / 每日首胜」入口，给回访一个理由
- 主按钮层级重排：开始匹配（主）> 编辑阵容（次）> 图鉴 / 排行

**2.3 匹配页**
- 保留旋转环，补「已等待 6 秒 · 搜索范围 ±100 分」的动态文案（已有逻辑，可视化更好）
- 匹配成功做揭晓演出：双方棋子从两侧对撞 + 昵称与积分滑入
- 长时间匹配不到时，给出「当前在线 N 人」或「创建房间」的出口

**2.4 结算页**
- 胜负演出：棋盘定格 → 斩帅特写 → 结算面板滑入
- 积分变化滚动动画（1016 → 1048）
- 战利品开箱：碎片 / 遗注逐个翻出，稀有度用光效区分

**2.5 新手引导**
- 首次进入对局页触发 3 步教学：选子 → 走子 → 攻击（高亮 + 文案气泡）
- 七种特性首次触发时，弹出一次性说明气泡
- 可跳过，跳过后在图鉴页留入口

**2.6 状态设计**
- 骨架屏替代「加载中…」
- 空状态插画（无对局 / 无排行 / 无阵容）
- 网络异常与重连提示（socket 断线时明确告知，而不是静默轮询）

**阶段二验收**
- 完整走一遍 首页 → 匹配 → 对局 → 结算，全程有音效、有过渡、无「哑场」
- 新玩家不看任何说明，能在引导下完成第一局

### 阶段三：内容深度 + 长期留存 + 打磨

**3.1 图鉴 ↔ 阵容打通**
- 图鉴页每枚棋子加「加入阵容」按钮，直接跳阵容编辑器并定位
- 阵容编辑器加「推荐阵容」模板，降低上手门槛

**3.2 赛季与巅峰榜**
- 首页那个「巅峰排行 · 即将上线」按钮兑现：赛季周期、赛季重置、赛季专属奖励
- 积分榜升级为赛季榜 + 历史最高分

**3.3 成就与任务**
- 成就：首次斩首、零阵亡取胜、连续 3 胜、用兵过河击杀等
- 每日 / 每周任务，与钱包和碎片系统打通

**3.4 复盘与观战**
- 服务端 `events` 已完整，直接做逐手回放（前进 / 后退 / 跳转）
- 结算页加「查看复盘」入口

**3.5 设置页**
- 棋盘主题（木纹 / 素色 / 深色）、音效与音乐开关、动画速度、认输二次确认、默认棋盘方向

**3.6 性能与兼容打磨**
- 低端机动画降级（粒子数量按设备能力裁剪）
- `prefers-reduced-motion` 已支持，补齐到所有新动效
- 首屏体积、字体子集化、图标 SVG 化

**3.7 文案与术语统一**
- 全站术语表：行动点 / 回合 / 阵容 / 遗注 / 碎片 / 斩首，统一口径

**阶段三验收**
- 老玩家有长期目标（赛季 + 成就 + 任务）
- 复盘能完整还原一局
- 低端机（4 年机龄中端安卓）稳定 30fps 以上

## 五、风险与取舍

1. **棋盘尺寸动态化会牵动整套定位**：`cellCenter()` 依赖真实 DOM 尺寸做特效定位，改布局时必须保证 CSS 变量与真实布局一致，否则刀光和伤害数字会错位。**建议先做一版可视原型验证，再动真实代码。**
2. **音效有移动端自动播放限制**：必须绑定首次用户交互解锁，否则 iOS 上静音。
3. **5 套主题**：每个新组件都要在明暗 / 羊皮纸 / 海洋下过一遍，工作量要算进去。
4. **阶段一改布局的收益最大但风险也最大**，建议单独一个分支做，做完立刻在真机上看三种尺寸。

## 六、需要拍板的问题

1. **视觉方向**：继续现在的「国风木纹 + 描金」，还是换一套更现代的风格？
2. **音效**：我去找 CC0 素材接上，还是你自己配？
3. **优先级**：手机优先还是桌面优先？（现在桌面棋盘只占 34% 宽，两边都有得改）
4. **赛季系统**：现在就规划进去，还是先聚焦单局体验、赛季往后放？
5. **原型**：阶段一要不要我先出一版 HTML 可视原型（不动真实代码）给你看效果，确认后再落地？
