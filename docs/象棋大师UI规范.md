# 象棋大师 UI 规范

> 线上 https://example.com/game/xqmaster
> 本文是界面设计与实现的唯一依据，改样式前先读这里。

## 一、整体布局

### 手机端（沉浸式强制横屏）
手机上不管设备怎么拿，界面一律按横屏铺满：全屏、隐藏系统 UI、隐藏站点导航与底部 tab。
整块舞台由 `XQM_LAND` 旋转 90° 生成，尺寸变量 `--ls`（长边）/ `--lw`（短边）/ `--lsf`（缩放）。

```
┌──────────────────────────────────────────────┐
│ 顶栏 48px   ← 退出 | 回合·计时 | 音效 设置     │
├───────────────────────┬──────────────────────┤
│                       │ 右栏 300px            │
│      棋盘（自适应      │  ① 当前回合 / 行动点  │
│      正方形最大化）    │  ② 选中棋子状态       │
│                       │  ③ 战报（可滚动）     │
├───────────────────────┴──────────────────────┤
│ 底栏 48px   我方头像·血条 | 势均力敌条 | 敌方  │
└──────────────────────────────────────────────┘
```

**区域职责**
- **顶栏**：只放全局操作（退出、音效、设置）与回合信息。不放进阶操作。
- **主区**：棋盘占满剩余空间；右栏固定 300px，内部纵向排列三块面板。
- **底栏**：双方状态与行动点。不放按钮（「结束回合」放在右栏第一块面板内，靠近棋盘）。

### 桌面端
同一套结构，右栏 320px，不需要旋转，`--btnav` 预留站点导航高度。

## 二、配色

统一走 CSS 变量，禁止在组件里写死颜色。

| 用途 | 变量 | 值 |
|---|---|---|
| 主色（红方 / 主按钮） | `--xqm-red` / `--xqm-red-dk` | `#A52222` / `#7A1212` |
| 金（强调 / 次要按钮） | `--xqm-gold` / `--xqm-gold-dk` | `#C9A227` / `#8C6E15` |
| 黑方 / 绿 | `--xqm-green` / `--xqm-green-lt` | `#1E4536` / `#2E6151` |
| 木纹底（棋盘） | `--xqm-wood1/2/3` | `#E3C79A` / `#D8B782` / `#C9A46A` |
| 格线 | `--xqm-grid` | `rgba(110,82,48,.42)`，深色 `rgba(205,180,135,.32)` |
| 页面底 | `--xqm-paper1/2/3` | 暖米黄三段渐变 |

**规则**
- 红=我方/进攻，绿=敌方/移动，金=强调/可攻击。同一含义全站同色。
- 状态色只用于状态，不用于装饰。棋盘木纹不跟随站点主题（五套主题下保持国风木色）。
- 深色主题只改底与线，不改语义色。

## 三、字体

| 用途 | 字族 | 字号 |
|---|---|---|
| 棋子字形 | 楷体 `STKaiti/KaiTi` | `calc(var(--sz) * .46)` |
| 标题（页面名 / 棋子名） | 宋体 `STZhongsong/Songti SC` | 19~30px，字距 `.12em` |
| 正文 / 按钮 | 系统无衬线 | 13~14px |
| 数值（血、攻击、计时） | 同正文 + `tabular-nums` | 12~16px |

**规则**：汉字标题一律加宽字距（≥`.1em`）出「碑帖感」；数值必须等宽数字，避免跳动。

## 四、按钮

四档层级，尺寸统一（触控高度 ≥44px）：

| 类 | 用途 | 样式 |
|---|---|---|
| `.xqm-btn-p` | 主操作（开始匹配 / 保存阵容） | 红渐变 + 内高光 |
| `.xqm-btn-g` | 次操作（结束回合 / 抽赏） | 金渐变 |
| `.xqm-btn-o` | 常规（返回 / 图鉴 / 取消） | 暖米底 + 金描边 |
| `.xqm-btn-d` | 危险（认输 / 退出对局） | 透明底 + 红描边 + 红字 |

**规则**
- 一屏内**最多一个主按钮**。
- 按下统一 `scale(.972)` + 内阴影；禁用统一 `opacity:.5` 且不响应。
- 退出 / 认输必须二次确认。

## 五、棋盘显示

- 9×10（对局）/ 9×5（首页·阵容）/ 由窗口决定（图鉴演示）——三套共用同一套绘制规则。
- 木纹底 + `inset 0 0 0 2px` 金色内描边 + 外投影。
- **格线画在棋盘层**（贯穿全盘的长直线），交点即落子点；**不要每格画十字**。
- 棋子：圆形玉牌，径向渐变 + 金色圈 + 底部投影；尺寸恒为 `calc(var(--cw) - 8px)`。
- 可移动=玉绿实心，可攻击=鎏金斜纹，预计伤害=红色数字。
- 等级只在入场动画期间显示，正式对局中不显示（看状态面板）。

## 六、交互反馈

| 时机 | 反馈 |
|---|---|
| 点击按钮 | 按下缩放 + 音效 |
| 走子 | 棋子位移动画 + 落子音 |
| 受击 | 棋子闪白 + 棋盘轻震 |
| 阵亡 | 金色碎片飞散 |
| 回血 | 绿色 `+N` 飘字 |
| 操作失败 | 顶部 toast（2 秒），不用弹窗 |
| 网络异常 | 顶部横条「连接中断，正在重连…」，恢复后自动隐藏 |

**规则**：同一动作永远给同一种反馈；错误一律 toast，不用 alert；所有动效受「完整动画」开关控制。

## 七、操作流程

```
首页 → 开始匹配 → 匹配成功(1.6s) → 对局 → 结算 → 再来一局 / 看复盘
                ↘ 取消匹配 → 首页
首页 → 编辑阵容 → 保存 → 首页
首页 → 棋子图鉴 → 详情 → 抽赏
```

- 对局中唯一出口是顶栏「退出」；退出需确认，退出后可回首页或直接回对局。
- 每一步都有明确去向，不留死路。
