# 中国象棋大师 · 设计文档

> 养成 + 对战的战棋玩法。棋子有独立血量、攻击力、攻击范围、移动方式和特性，
> 被攻击只掉血，血量归零才离场。匹配制对战（**纯真人，不做 AI**）。
>
> 状态：设计稿 · 2026-09-29
> 本轮**只做对战本体**，养成系统按下面的方案预留接口，暂不实现。

---

## 一、一句话定位

**把中国象棋从「一步定生死」改成「你来我往打血条」的战棋。**

原版象棋：吃子即秒杀，一步失误满盘皆输。
本作：棋子有血条，挨打只是掉血，可以退、可以换、可以拖。
节奏更慢、容错更高、战术空间更大 —— 适合学生课间几分钟一局。

## 二、棋盘与回合

### 棋盘
沿用标准中国象棋棋盘：**9 列 × 10 行**，中间河界，两端九宫。
棋子摆位与原版一致（每方 16 枚）。

### 回合结构
**双方轮流，每回合 3 个行动点。**

| 动作 | 消耗 | 说明 |
|---|---|---|
| 移动 | 1 点 | 按该棋子自己的移动方式走到**空格** |
| 攻击 | 1 点 | 对**攻击范围内**的敌方棋子造成伤害 |

- 同一个棋子在一回合内可以「先移动、再攻击」（各消耗 1 点）—— 这是**冲锋类特性**的前提
- 攻击不移动、移动不攻击，两者独立
- 3 点用完换对方

> 为什么是 3 点？一局大约 8~12 回合结束，单局 3~6 分钟。
> 1 点太慢（16 个棋子打不完），5 点太快（一回合就能形成合围，没得翻盘）。

### 胜负判定
1. **斩首** —— 对方「将/帅」血量归零，立即获胜（唯一胜负条件）
2. **僵局** —— **不设回合数上限**，但统计「连续无伤害回合」：
   双方连续 **10 个回合**都没有任何棋子掉血，判和（防双方都龟缩不出手）
3. 双方都无棋可动 → 判平

> 选斩首而不是全歼：象棋的直觉就是"擒王"，全歼会拖到十几分钟，不适合课间。
>
> ⚠️ **取消回合上限的副作用**：原本 20 回合封顶能兜住"谁都不进攻"的局面，
> 现在没有上限了，所以必须有「连续无伤害回合」这条兜底 ——
> 否则两个保守的玩家可以无限对峙下去。10 回合这个数可以调。

## 三、棋子设计

### 数值总表（1 级基准）

| 棋子 | 数量 | HP | ATK | 移动方式 | 攻击范围 | 特性 |
|---|---|---|---|---|---|---|
| 帅 / 将 | 1 | **300** | 30 | 九宫内横竖斜 1 格 | 九宫内 1 格 | **帅令**：周围 1 格内友军受到伤害 **-50%** |
| 仕 / 士 | 2 | 120 | 25 | 九宫内斜 1 格 | 斜 1 格 | **舍身**：紧邻帅/将时，替其承受 30% 伤害 |
| 相 / 象 | 2 | 140 | 25 | 田字（不塞象眼、**可过河**） | 田字 | **厚甲**：受到的远程伤害（车/炮）额外 -25% |
| 马 | 2 | 110 | 55 | 日字（不蹩马腿） | 日字（可越子） | **冲锋**：本回合先移动再攻击时，伤害 +20% |
| 车 | 2 | 150 | 60 | 直线任意格（不越子） | 直线 3 格内 | **破甲**：攻击时无视目标 20% 的减伤效果 |
| 炮 | 2 | 100 | 70 | 直线任意格（不越子） | 直线，**需隔 1 子**才打得到 | **轰击**：对目标身后 1 格造成 40% 溅射伤害 |
| 兵 / 卒 | 5 | 80 | 35 | 未过河：正前 1 格<br>过河后：前 / 左 / 右 1 格 | 同移动方式 | **锐气**：过河后 ATK +50% |

**单方总血量 1940**（将帅从 200 提到 300 后 +100），平均一局双方合计约 3200~3800 点伤害交换。

### 几个关键设计取舍

**① 攻击范围 ≠ 移动方式**
用户明确要求两者独立。上表里 兵/仕/相/马 的攻防范围恰好一致，
但**车和炮故意做成不一致**：
- 车能跑全盘，但只能打 3 格内的目标 → 逼你贴上去打
- 炮移动无限制，但攻击必须**隔一个子**（借用象棋"炮打隔子"）→ 需要自己摆"炮架"

这样「移动」和「攻击」就成了两套需要分别规划的维度，而不是一个动作的两种说法。

**② 为什么车不能无限距离攻击**
如果车能隔全盘打，那开局就能隔着棋盘互射，谁先手谁赢 —— 没得玩。
限制 3 格让它必须进入对方的反击范围，形成"贴脸换血"的博弈。

**③ 炮的溅射方向**
"身后 1 格"= 从炮到目标连线的延长线再一格。
这让炮在打成一团的局面里特别强，但单挑时很弱 —— 鼓励抱团推进。

**④ 相/象：不塞象眼，而且可以过河**
原版象棋里相/象既塞象眼、又过不了河，基本只能在自己半场当摆设。
这里两条都放开：**田字随便跳、还能过河**。
它是本方血量第二高的棋子（140），放开之后可以真正参与进攻，而不是缩在后面。

**⑤ 将/帅 300 血 + 有攻击力**
不是"碰一下就死"的吉祥物。它可以自保、可以补刀，
但**不能出九宫**——九宫就是它的牢笼，也是它的堡垒。

**⑥ 帅令 50% 是有意做强，但要知道它的后果**
50% 减伤意味着**围在帅周围的棋子几乎打不动**。这会让「全员缩回九宫附近」成为一种强势打法 ——
谁先主动进攻谁吃亏。

如果实战发现大家都在龟缩，有两个调整方向（先按 50% 做，跑起来再调）：
- 把范围从「周围 1 格」缩小到「紧邻的 1 枚棋子」
- 或者降到 30%，同时给「车」的破甲加强，让它能啃动龟缩阵

## 四、伤害计算

```
实际伤害 = 攻击力 × 特性加成 × (1 - 总减伤率)
总减伤率 = 1 - (1 - 帅令) × (1 - 厚甲) × (1 - 其他)
```

- **减伤是乘法叠加**，不是加法 —— 防止堆到 100% 免伤
- 减伤上限 **70%**，硬性封顶
  （帅令 50% + 厚甲 25% 乘算 = 62.5%，还没顶到上限；留出余量给以后的养成加成）
- 溅射伤害按**未减伤前**的伤害乘 40%，再各自结算减伤

**举例**：马（55 ATK）冲锋攻击被「帅令」保护的象
```
55 × 1.2（冲锋）        = 66
66 × (1 - 0.50 帅令)    = 33
   注意：马是近战，象的「厚甲」只对远程生效，这里不减
最终 33 点
```

> 对比一下：同样这一击如果**不在帅的旁边**，就是满额 66 —— **整整差一倍**。
> 这就是 50% 帅令的威力，也是它可能催生"龟缩流"的原因。

## 五、匹配逻辑

### 段位与积分
| 段位 | 积分区间 |
|---|---|
| 青铜 | 0 – 899 |
| 白银 | 900 – 1099 |
| 黄金 | 1100 – 1299 |
| 铂金 | 1300 – 1499 |
| 钻石 | 1500 – 1699 |
| 大师 | 1700+ |

初始 **1000 分**。胜负按 Elo 结算（K=32），对手分差越大，赢得越多、输得越少。

### 匹配流程
```
进入队列
  ↓
每 5 秒放宽一次分段窗口：±50 → ±100 → ±150 → ±250 → 不限
  ↓
匹配到 → 开局
  ↓
超过 20 秒仍无对手 → 提示「暂时没人在线，继续等还是先退出？」
       [ 继续等 ]   [ 退出队列 ]
```

- **纯真人匹配，不做 AI 兜底**（用户明确要求）——
  代价是人少的时候可能真的要等，尤其深夜或刚上线时。
  站点用户量不大，这一点要有预期
- 断线处理：单方掉线超过 45 秒判负；双方掉线则本局作废
- 同一用户不能同时进两个匹配队列

### 防作弊要点
- 所有走子**必须服务端校验**（复用现有棋类房间的 `legal` 校验思路）
- 每回合有 **60 秒**操作时限，超时自动结束该回合
- 同一用户不能同时进两个匹配队列

## 六、养成系统（本轮不实现，先留接口）

### 货币
**棋魂** —— 游戏内专用货币，与站内积分完全隔离。

| 来源 | 数量 |
|---|---|
| 排位胜利 | +30 |
| 排位失败 | +10（保底，不让新手玩不下去） |
| 每日首胜 | 额外 +50 |
| 连胜 3 / 5 / 10 场 | 额外 +30 / +80 / +200 |

### 棋子升级
- **每个棋子独立等级**，1 ~ 10 级
- 每级 **HP +5%、ATK +5%**（相对 1 级基准，线性叠加）
- **3 / 6 / 9 级**解锁特性强化（例如 马 6 级：冲锋加成 20% → 30%）
- 升级成本递增：`成本 = 20 × 等级²`（1→2 级 20 棋魂，9→10 级 1620 棋魂）

> 设计意图：升满**一个**棋子很快（有成就感），升满**一整套**很慢（长期目标）。

### 平衡原则
- **不做"付费变强"**，棋魂只能靠打
- 排位匹配**只看积分**，不看棋子等级 —— 否则新手必输
- 但可以在赛前显示双方棋子等级，让玩家自己选择要不要打（心理博弈）

## 七、界面风格：国风棋枰

### 配色
| 用途 | 色值 | 说明 |
|---|---|---|
| 棋盘木色 | `#D9B98C` → `#C9A87A` | 浅木纹，纵向渐变 |
| 河界 | `#8FA88F` 半透明 | 墨绿水纹，写「楚河」「汉界」 |
| 红方主色 | `#8B1A1A` | 朱红（棋子、血条、己方高亮） |
| 黑方主色 | `#1B3A2F` | 墨绿（棋子、血条、对方高亮） |
| 鎏金描边 | `#C9A227` | 选中态、攻击范围高亮、边框 |
| 宣纸底 | `#F5F0E6` | 页面背景 |

**明确避开纯黑白灰** —— 用朱红 / 墨绿 / 鎏金 / 木色四个色相撑起整张画面。

### 棋子造型
- **圆形玉牌**，直径约 62px，带 1px 鎏金内圈
- 红方：朱红玉（`radial-gradient` 从 `#A52222` 到 `#7A1212`）
- 黑方：墨绿玉（从 `#22493C` 到 `#12261F`）
- 棋子文字：白色宋体，带极细的暗色描边保证可读
- **受击反馈**：玉牌出现裂纹（SVG 描边），裂纹数量随血量下降增加

### 血条
- 位置：棋子下方，宽 54px、高 5px，圆角
- 颜色：满血 `#4A8B5C`（玉绿）→ 半血 `#C9A227`（鎏金）→ 残血 `#A52222`（朱红）
- 掉血时**左侧留一条浅色残影**，让玩家看清这一下掉了多少

### 攻击范围高亮
选中棋子时，可攻击的格子铺一层**鎏金斜纹**（`repeating-linear-gradient` 45°），
可移动的格子铺**半透明玉绿**。两套高亮用不同纹理区分，不用不同颜色（色盲友好）。

### 动效清单

**A. 棋子本体**

| 触发 | 效果 |
|---|---|
| 悬停 | 抬起 3px + 放大 1.05，180ms 回弹曲线 |
| 选中 | 抬起 4px + 放大 1.07，外圈鎏金环**呼吸脉冲**（1.5s 循环） |
| 待机 | 极轻微的呼吸缩放（1.0 ↔ 1.008，4s 循环）—— 让棋盘看起来"活的" |

**B. 范围高亮**（填满整格，不是小圆点）
- 可移动 = **玉绿实心块** + 内描边 + 外发光
- 可攻击 = **鎏金 45° 斜纹** + 内描边
- 两者重叠 = 两层叠加
- 范围内有敌人 = 套一圈**朱红脉冲环**
- 出现动画：从中心 `scale(.55)` 弹到 1，260ms，逐格错开 15ms 形成波浪

**C. 移动**
- 棋子沿路径滑动 200ms `ease-out`
- 拖尾：沿路径留下 **7 段渐隐残影**，逐段缩小并淡出
- 落点微尘：到达时地面泛起一圈极淡的土色涟漪

**D. 攻击（本作最重的特效，分五层）**
1. **起手蓄力** —— 攻击方下沉 `scale(.94)` 95ms，再前冲 `scale(1.06)`
2. **刀光本体** —— 采样贝塞尔生成「中间粗、两端尖」的实体形状（宽度 `sin(πt)^0.62`），
   三层叠加：19px 金色模糊光晕 + 9.5px 五段渐变主体 + 2.8px 纯白核心
3. **扫出** —— 用宽度 0→满的 `clipPath` 裁剪，刀光沿弧线扫过去，190ms 缓出
4. **飞溅火星** —— 扫描过程中每 13% 从弧线两侧甩出火星，左右交替，带随机角度
5. **命中爆点** —— 径向白光（scale 0.18→1.55）+ 金色扩散环（0.28→1.95）+ 7 根放射尖刺

**伤害类型用不同颜色区分**：近战=鎏金、远程=青白、溅射=赤橙。

**E. 受击**
- 玉牌**闪白**（`brightness(2.6)`）340ms
- **震屏**：整个棋盘横向抖动 ±6px，320ms
- **伤害数字**：从命中点向上飘，先放大到 1.22 再回落，最后缩小淡出，1.05s
- **血条掉血**：填充条缩短，**左侧留一条浅色残影**慢慢追上 —— 让玩家看清这一下掉了多少
- **裂纹生长**：新裂纹从撞击点向末端"爬"出来（`stroke-dashoffset` 动画），受击瞬间加速到 240ms

**F. 死亡**
- 玉牌沿 8 个扇形方向**碎成 8 块**，向外飞散 + 随机旋转 + 缩小淡出，620ms
- 碎片带鎏金内圈描边，看起来像真的玉片
- 原地留下半透明幽灵，随后飘出「棋子阵亡」

**G. 回血**
- 玉牌泛绿光（`brightness(1.35)` + 绿色投影），1s
- 绿色 `+N` 从棋子向上飘

**H. 氛围与状态**（让画面"多一些"的部分）

| 效果 | 说明 |
|---|---|
| **环境聚焦** | 选中棋子时，棋盘四角轻微压暗，视线自然聚焦到高亮区域 |
| **河界水波** | 「楚河」「汉界」四个字有极缓慢的亮度呼吸，像水面反光 |
| **连击反馈** | 同一回合连续命中同一目标，伤害数字逐次变大、颜色转橙红 |
| **低血警示** | 己方棋子血量 <20% 时，血条脉冲闪烁 + 玉牌边缘泛红 |
| **回合切换** | 顶部横幅从侧边滑入「轮到你了」/「对方思考中」，400ms |
| **开局入场** | 16 枚棋子从棋盘两侧依次滑入落位，每枚错开 40ms |
| **终局** | 斩首时全屏短暂鎏金闪光 + 对方将帅慢镜头碎裂（0.4 倍速） |

**性能约束**（这台机器只有 2GB 内存，但特效全在客户端跑，不影响服务器）：
- 全部用 `transform` / `opacity` 驱动，不触发重排
- 粒子数量封顶（火星同时最多 12 颗，碎片固定 8 块）
- 尊重 `prefers-reduced-motion`：用户系统开了"减少动态效果"就关掉震屏和粒子

## 八、技术实现要点

### 数据表
```sql
-- 对局
CREATE TABLE xqmaster_games (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    red_id      INTEGER NOT NULL,
    black_id    INTEGER,              -- NULL = 等待中
    is_ai       INTEGER DEFAULT 0,
    state       TEXT NOT NULL,        -- JSON：16×2 个棋子的坐标/血量/状态
    turn        INTEGER DEFAULT 0,    -- 0 红 1 黑
    ap          INTEGER DEFAULT 3,    -- 本回合剩余行动点
    round       INTEGER DEFAULT 1,
    status      TEXT DEFAULT 'waiting', -- waiting/playing/finished
    winner      INTEGER,              -- 0 红 1 黑 -1 平
    rating_red  INTEGER, rating_black INTEGER,
    created_at  REAL, updated_at REAL
);

-- 匹配队列（内存表也行，落库便于重启恢复）
CREATE TABLE xqmaster_queue (
    user_id  INTEGER PRIMARY KEY,
    rating   INTEGER NOT NULL,
    joined_at REAL NOT NULL
);

-- 棋子等级（养成用，本轮先建表不启用）
CREATE TABLE xqmaster_pieces (
    user_id  INTEGER NOT NULL,
    piece    TEXT NOT NULL,           -- king/advisor/elephant/horse/chariot/cannon/pawn
    level    INTEGER DEFAULT 1,
    PRIMARY KEY (user_id, piece)
);
```

### 复用现有基建
- **走子校验**：参考现有 `xq` 房间的 `legal` 生成逻辑（但**规则完全不同**，要重写）
- **实时同步**：复用站内已统一的**单条长连接**（`window.__monoSio`），不要新开
- **防重复提交**：走子接口套 `repeat_guard`（本轮刚做的那套）
- **断线重连**：状态全在服务端，客户端只管渲染，重连后拉一次 state

### 性能注意
- 棋盘状态用紧凑结构（7 种棋子 × 最多 16 枚，JSON 约 1.5KB），每次走子整包推送即可，不用增量
- 匹配队列放内存 + 定时落库，避免每次轮询都查库
- 这台服务器只有 **2GB 内存**。**因为不做 AI，省掉了最大的一块开销** ——
  不用接 Pikafish/Stockfish，也不用在服务器上跑任何搜索。整局逻辑就是纯规则计算，
  开销可以忽略

## 十一、待确认的问题

1. **将/帅 能不能出九宫？** 文档里定的是不能（保留象棋直觉）。如果想让将帅更主动，可以改成"能出九宫但移动力受限"。
2. **相/象 要不要塞象眼？** 文档里定的是不塞（体验优先）。塞的话更还原象棋，但高血量棋子被小兵卡死会很憋屈。
3. **炮的攻击必须隔子**，这个要不要保留？保留很有象棋味，但新手可能不理解。
4. **「连续无伤害回合」判和的阈值定几回合？** 取消回合上限后这是唯一的僵局兜底。
   文档暂定 **10 回合**。定太小会误伤"试探期"，定太大起不到防龟缩的作用。
5. **帅令 50% 是否要收一收？** 现在的数值会让"缩在九宫"成为强势打法，详见第四章第 ⑥ 条。
   建议先按 50% 做出来，跑几局看看实际体感再调。
6. **匹配不到人怎么办？** 取消 AI 后这是真实风险 —— 站点人不多，深夜可能真匹配不到。
   要不要加个「创建房间等朋友加入」的入口作为补充？
