> 游戏本身的视觉基调（提示词里要延续，别让海报和站内长得像两个游戏）：
> - 主色：深红 `#8B1A1A` / 金 `#C9A227` / 墨绿 `#1B3A2F` / 木色 `#E3C9A2`
> - 字体气质：宋体、楷体（衬线），不用黑体
> - 核心意象：木质棋盘、红金棋子、宣纸、印章
