## 〇、第一批实现记录（2026-10-07）

### 落地时拍板的口径

设计稿里「直线 1~2 / 相邻」「攻击直线 3 格」这类写法没说清方向数和是否穿子，实现时统一成：

| 写法 | 含义 |
|---|---|
| 走法「直线 N」 | 上下左右**四方向**，最多 N 格，遇到棋子就停 |
| 走法「相邻」 | 上下左右四方向的相邻 1 格 |
| 攻击「直线 N 格」 | 四方向上、距离 ≤N 的**第一个**棋子；**不穿子** |
| 「相邻友军 / 相邻敌人」类的光环与触发 | **八方向**（与既有的粮·补济、仕·护主、相·掠阵保持一致） |

所以弓（攻击直线 3 格）打得到 2~3 格外的第一个敌人，**打不到贴着它的那个**。
只有明确写了「可越过棋子」的（鹰，第二批）才忽略路径上的棋子。

### 行动点模型（原第六节问题 1 的答复）

- 全局行动点**每回合恒为 3 点**，不变。
- 每个棋子另有「本回合还能行动几次」的预算，默认 1 次。
- **一次行动同时消耗 1 点行动点和 1 次预算**。
- 探·游走自带 2 次预算；鼓·催战让相邻友军 +1，鼓·战鼓让全军 +1。
- **加成取最大值，不累加** —— 否则帝（第二批）+ 鼓会让行动点彻底失控。
- 所以鼓不抬高行动点，只把两次行动塞给同一个棋子。

### 反伤（原第六节问题 2 的答复）

- 反伤**算伤害**（计入「无伤害回合」计数，防止被判和）、**可以击杀**。
- 但走**独立的 reflect 事件**，不触发「击杀后」类特性（虎的再行动、刺的影袭）。
- 反伤本身不受任何增伤 / 减伤修正；明镜（镜 20 级）按**未减伤的原始伤害**计算。
- **被影袭免疫掉的那一击不算打中，因此也不反弹。**

### 上限（原第六节问题 3 的答复）

按第二节表格落地（不是第四节建议的「普通 3~5」）：
卒 8 · 民 6 · 矢 4 · 牌 4 · 探 3 · 火 3 · 卓越一律 2 · 神话 1。
`LINEUP_TOTAL` 仍是 16，所以 28 选 16 必须放弃东西。

### ⚠️ 上线后要盯的两件事

1. **卒 过河后 ×2.6（30 → 78），而且上限 8 枚。** 普通品质里这是明显的数值超标，
   模糊测试里它是最容易滚雪球的一枚。如果线上出现「八卒渡河」的无脑打法，
   优先把「老卒」从 ×2 降到 ×1.5。
2. **对局被拉得很长。** 随机走子的模糊测试里，对局长度中位数 942 ply（约 471 回合），

   真人打不会这么极端，但上线一周后要重点看**平均对局回合数**有没有明显上涨。

### 顺手修掉的既有 bug

- 粮的移动高亮会把敌人占住的格子标成「可走」，点下去却提示走不过去。
- 图鉴里粮·补济的演示场景配了攻击类演示，但粮不可攻击 → 点了完全没反应。
- 图鉴预览的「破甲 无视 X% 减伤」与服务端说明文案不一致。
- 前端伤害预览漏了粮·振饱（两格内减伤 20%）和兵·浴血（过河后单次伤害封顶 25%）。
- 战斗页阵亡碎裂特效取了不存在的 `ev.tr/ev.tc`，从来没触发过。

## 〇·二、第二批实现记录（传说 6 + 神话 2）

### 落地时新增的口径

| 写法 | 含义 |
|---|---|
| 龙「攻击直线 3 格内穿透」 | 打直线上距离 ≤3 的**第一个**棋子，并**穿透**命中它身后的第二个（伤害不衰减） |
| 鹰「翱翔 / 移动时无视阻挡」 | 移动时**忽略路径上的一切棋子**，但不能落在有子的格上 |
| 龙「腾云」 | **每回合一次**：这一次移动可以无视阻挡（移动后机会就用掉了） |
| 虎「猛扑」 | 击杀后**补回本回合的行动次数** —— 净效果是这一击不占行动预算，但**照付行动点** |
| 豹「疾行」 | 行动预算 2（与探·游走同一机制） |
| 豹「残影」 | 移动之后，**对手这一轮**打它的第一下直接落空 |
| 医「回春」 | **新增第三种动作**：选中医 → 点相邻友军 → 花 1 点行动点治疗，回复目标 **25% 生命上限** |
| 医「妙手」 | 治不进去的部分转成**护盾**，先替目标挨伤害；护盾**上限等于目标生命上限** |

### 行动点与帝（原第六节问题 1 的最终答复）

- 全局行动点基础仍是 3 点。**帝·御驾 +1 → 4 点**。
- 规则是「**同类加成取最大值，不累加**」：`_ap_max()` 里所有来源取 max。
- 鼓不在这条线上 —— 它只抬高**棋子行动次数**，不抬高行动点。所以「帝 + 鼓」不会变成 5 点，
  而是「4 点行动点 + 每个棋子能行动两次」。这是有意分开的两条资源线。

### 主帅位现在是三选一

`帅 / 君 / 帝` 三选一（`BOSS_TYPES`）。三者都会被**斩首**判负，
`piece_zone` 里三者都限九宫，`validate_lineup` 检查三者合计为 1。

⚠️ **顺带修掉一个老 bug**：原来 `_apply_damage` 里只有 `t == "king"` 才触发斩首结束，
**打死君根本不结束对局**（君有 500 血，是全队最肉的一个）。
现在改成 `t in BOSS_TYPES`，君和帝都能被斩首。

⚠️ **坐镇（帅的 40% 宫防）现在只归帅和君**。原来这段判定用的是 `_find_king` 的结果、
没限定类型，所以君也一直在白拿一个没写进说明的 40% 光环；帝加进来之后会变成「白捡」，
所以加上了类型限定 —— 帅/君的行为**没有任何变化**，只是帝不会继承。

### 新增状态字段

| 字段 | 含义 |
|---|---|
| `kb` | 虎·百兽本回合的连续击杀层数（回合开始清零；没打死人清零） |
| `cl` | 龙·腾云本回合还剩几次无视阻挡（回合开始发放，移动后用掉） |
| `sh` | 护盾点数（医·妙手产生；`_apply_damage` 里先扣它） |

### 定稿数值

| 棋子 | 血 | 攻 | 初始特性 | 20 级特性 |
|---|---|---|---|---|
| 虎 | 150 | 80 | 猛扑：击杀后补回行动次数 | 百兽：连续击杀 +20%（不封顶） |
| 豹 | 130 | 65 | 疾行：行动预算 2 | 残影：移动后免疫一次攻击 |
| 鹰 | 130 | 70 | 翱翔：移动无视阻挡 | 鹰眼：无视目标 20% 减伤 |
| 狼 | 140 | 60 | 群猎：每个相邻友军 +8% 攻击 | 头狼：相邻友军攻击 +12% |
| 医 | 150 | 0 | 回春：治疗相邻友军 25% 生命上限 | 妙手：溢出转护盾 |
| 匠 | 150 | 0 | 铸兵：相邻友军攻击 +15% | 神工：全军攻击 +8% |
| 帝 | 320 | 60 | 御驾：全军行动点 +1 | 亲征：全军攻击 +15% |
| 龙 | 300 | 110 | 龙威：无视目标 30% 减伤 | 腾云：每回合一次无视阻挡移动 |

### ⚠️ 上线后要盯的事

1. **虎·百兽不封顶**。猛扑（击杀补回行动）+ 百兽（每次连杀 +20%，无上限）叠在一起，
   面对一堆残兵时攻击力会滚到很高。如果线上出现「一只虎清场」，给 `HU_MIGHT` 加个层数上限。
2. **帝 + 鼓 的节奏流**：4 点行动点 + 全军行动两次，一回合能做的事明显变多。
   这是设计稿里点名的「节奏滚雪球」流派，但也是这次改动里最可能破坏平衡的一条。
3. **医·妙手的护盾可以跨回合累积**（上限是目标生命上限）。配合高血量的君/龙，
   可以提前把护盾堆满再推进。如果太强，考虑给护盾加「每回合衰减」。

## 〇·三、第三批实现记录（优良 8 · 重做版，2026-10-08）

> ⚠️ 这一档**做过两遍**。第一遍把优良做成了「卓越的数值降级版」（骑/甲/戟/哨/辎/机），
> 违反了「不做平替」的要求，上线当天就整批撤掉重做。现在的 8 枚各开一个新机制。

### 六套新机制怎么落的

**1. 移形（移）—— 第三种动作**

以前棋子只能「走 / 打 / 治」，移开了「换位」。
`legal_targets()` 的第三个集合本来只给医·回春用，现在**同时装移的换位对象**
（都是「己方棋子占住的格」）—— 所以它俩的判断必须**按棋子类型分派**，
而且**移形分支要排在回春前面**，否则移一出手就变成给友军加血了。

**2. 替死（卫）—— 拦截致命伤害**

在 `_apply_damage()` 里做：扣血之前先看这一下会不会打死人，
会的话找旁边**没用过替死**的己方卫，把这一击整个转嫁过去。

- 卫自己挨打时不会替自己死（判断 `target["t"] != "wei"`）
- ⚠️ **死士的回血必须等伤害结算完再做**。先回再挨打的话，回的那点血当场又被扣掉，等于没回
- 预览（前端 `resolveAttack` + 交叉验证的 Python 版）也模拟了这一步，
  否则玩家看到的伤害落点会和服务端不一致

**3. 蓄势（蓄）—— 用一回合换爆发**

回合开始时看上一回合的 `ad`（出过手没有）：没出手就置 `ch=1`，出手了就清掉。
`calc_damage()` 里 `ch` 存在则伤害 ×2。

⚠️ 棋子创建时 `ad` 初始为 `True`（当它「上一回合出过手」），
否则刚上场第一回合就白送一次蓄力。

**4. 标记（标）—— 把「打谁」变成团队决策**

命中后给目标挂 `mk`（到期 ply）和 `mks`（标记方）。
`calc_damage()` 里只要攻击方和 `mks` 同边、且没过期，就 +15%。
所以**标记只帮自己人**，敌人打它没有加成。

**5. 断粮 / 断援（断）—— 拆续航**

命中后挂 `nh`（到期 ply），`_can_heal()` 会在所有回血路径上拦一道：
粮·补济 / 药·施药 / 良方 / 医·回春 / 民·征召 / 乡勇 / 死士 全都认这个标记。

20 级的断援再加一个 `nb`，把**减伤光环整个清零**，并让**六处攻击光环**
（旗·号令 / 大纛 / 帝·亲征 / 狼·头狼 / 匠·铸兵 / 神工）对它失效。

**6. 残兵（残）—— 死两次**

在 `_apply_damage()` 的阵亡分支里拦一道：是残且没用过 `rev`，
就以 30%（不屈 50%）生命站起来，**不产生 kill 事件**。
所以「击杀后」类特性（虎·猛扑、刺·潜行、百兽）都不会因为「打死了残」而触发。

### 顺手修掉的三个既有问题

1. **走法高亮不判占位**：卒 / 民 / 牌 / 火 / 医 / 移 这些「直线 1」的棋子，
   走法集合里包含了被占住的格子 —— 前端会把它高亮成「可走」，点下去才报「走不过去」。
   各分支自己判容易漏，现在**在 `legal_targets()` 末尾统一兜一道**
   （攻击范围不受影响，照样能打）。
2. **死士的回血顺序**（见上）—— 这是重做时新写的代码，测试当场抓出来的。
3. **医的治疗目标没排除被断粮的友军** —— `legal_targets()` 说能治、`apply_action()`
   又拒绝，前端会高亮一个点下去报错的格子。
   ⚠️ 这个是**贪心 AI 对局模拟**（`sim_balance.py`）跑出来的：它按预览挑动作，
   挑到一个「预览合法、实际非法」的格子就直接抛异常。
   顺手把治疗目标收窄成「受伤且没被断粮的相邻友军」——
   顺便也让前端的绿圈不再高亮满血友军。
## 〇·四、平衡实测（贪心 AI 对局，2026-10-08）

随机走子测不出平衡（双方都在乱走 → 97% 判和、中位数 942 ply）。所以另写了一个
**贪心 AI 对局模拟**（`_trash_wip/xqm-batch1-tests/sim_balance.py`）：
优先打死人、优先打残血、优先打贵的、该治就治、没事干就往前压。

```bash
$PY _trash_wip/xqm-batch1-tests/sim_balance.py 30 111   # 局数 种子
```

### 好消息：对局长度不是问题

| 指标 | 随机走子 | 贪心 AI |
|---|---|---|
| ply 中位数 | 942（约 471 回合） | **117~157（约 58~78 回合）** |
| 判和率 | 97% | **17%~30%** |
| 分不出胜负 | 16% | **0%** |

第一批上线时担心的「药 + 粮 + 盾 + 阵 续航过强导致对局拖不完」，
**在会玩的对手之间不成立** —— 随机走子那 942 ply 是假象，两边都在浪费行动点而已。

### 稳定出现的偏强项（5 个种子跑出来的）

| 棋子 | 档位 | 场均输出 / 同档均值 | 怎么看 |
|---|---|---|---|
| **马** | 卓越 | **2.4~2.8 倍** | 「八面威」每个相邻敌人 +15% 且**不封顶**，冲进人堆能吃满。5 个种子里 4 个偏高，是最稳的信号 |
| **戟** | 优良 | **3.0~3.6 倍** | 横扫打「目标相邻的所有敌人」，AoE 在 16v16 混战里天然总伤高 |
| **火 / 炮 / 龙** | 普通 / 传说 / 神话 | 各自同档 2.3 倍左右 | 同上 —— **AoE 棋子普遍是同级总伤的 2~3 倍** |

**结论：这不是某一枚超模，是「AoE 在密集阵型里太吃香」这个结构性问题。**
要压的话有三个杠杆：① 戟的横扫比例（50% → 35%）；② 戟的横扫改成只打一个目标；
③ 马的八面威加个上限（比如最多 +60%）。**都没动，等你看过再说。**

### 稳定出现的偏弱项

| 棋子 | 档位 | 场均输出 / 同档均值 | 怎么看 |
|---|---|---|---|
| **帝** | 神话 | **14%~32%** | **指标盲区**：帝的价值是「御驾」（全军行动点 +1），输出表里完全看不见。5 个种子全都低，但这是指标问题不是数值问题 |
| **仕** | 优良 | 15%~27% | 防御型辅助（护主分担伤害），本来就打不出伤害 |
| **弓** | 卓越 | 约 38% | 「劲射打不到相邻」在实战里代价很大 —— 对面一贴身它就哑火 |
| **斥 / 哨** | 卓越 / 优良 | 40% 左右 | 侦察 / 光环类，正常 |

### 这个工具的盲区（写在脚本输出里了）

- 纯光环/辅助（粮 旗 鼓 阵 药 医 匠 辎）本来就是 0 输出，正常
- 帝的御驾、豹的疾行（双倍输出但要吃两点行动点）、矛的反伤（算进它的输出）
  这些「代价」或「隐形收益」都看不出来
- **样本量偏小**（每种棋子每轮约出场 30 次），单次跑出来的排名波动很大 ——
  **只有换几个种子都出现在同一位置的项才值得动**

## 一、设计原则

### 1. 每个棋子必须回答一个问题
不是"数值更高"，而是**"它能解决什么别人解决不了的问题"**。
一个棋子如果只是"攻击更高的车"，那它不该存在 —— 它是数值膨胀，不是设计。

### 2. 流派靠"协同"而不是"同类堆叠"
现有 `粮` 的补济/振饱就是范例：它自己不能打，但**让周围的东西变强**。
新棋子按三种协同方式分类：
- **光环型**（站桩给周围加成）→ 支撑"阵地流"
- **触发型**（做某件事时给队友收益）→ 支撑"连锁流"
- **克制型**（专门拆对面的某种套路）→ 支撑"针对性换人"

### 3. 品质 = 稀有度，不等于强度
神话是**规则级**的（改变一条游戏规则），传说**改变一条战斗公式**，
卓越是**一个明确的战术功能**，普通是**便宜好用的零件**。

### 4. 16 格上限是流派的核心约束
一局只能带 16 个。36 选 16 → **必须放弃一些东西** ✗ 这就是流派的来源 ✓

## 四、平衡基线（供实现时参考）

- **攻击力梯度**：普通 30~40 / 卓越 45~70 / 传说 60~90 / 神话 90~120
- **生命梯度**：普通 60~100 / 卓越 90~140 / 传说 120~180 / 神话 300~500

  是 3 点的 1.67 倍 → **必须限制**（建议：行动点加成取最大值而非累加 ✗ 不叠加）
- **上限建议**：神话 1 · 传说 2 · 卓越 2 · 普通 3~5（与现有 `PIECE_COUNTS` 同风格）
