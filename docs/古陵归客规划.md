# 「古陵归客」分阶段开发规划（v2 · 对齐《超自然行动组》）

> 2026-09-26 重写。玩法全面参考《超自然行动组》（摸金撤离模式），题材换成中式古墓。
> 当前阶段仅超管可见，验证成熟后决定是否全量开放。

## 一、与原作的机制映射

| 原作（超自然行动组） | 网页版「古陵归客」 |
|---|---|
| 摸金撤离：限时收集文物达金额（浅层 1 万/深层 2.5 万）后撤离 | 摸金撤离：限定 12 分钟，收集古墓文物达目标金额，回马车提交并撤离 |
| 局外配装：每局最多带 4 件装备（探测/防护/干扰/辅助） | 局外配装：进墓前选 4 件装备，用累计收益解锁更多装备 |
| 角色技能（侦查/治疗/战斗专家） | 暂不做：所有玩家同质，先靠装备拉开打法差异 |
| 道具互动：电磁枪控怪、葫芦收服、桃木剑斩杀 | 同款中式装备：电磁枪（吸附定身怪物 3 秒）、葫芦（收服小怪换钱）、桃木剑（近战斩杀）、黑驴蹄子（驱退怪物）、探阴爪（远距取物） |
| 动态危险：拿到龙珠等高价值物后全图危险度上升 | 拿到「墓中之王」级文物（和氏璧残片/九鼎之一）后全图怪物刷新加速、移速提升，逼你见好就收 |
| 怪物：鬼新娘/提线木偶/嗜血蝙蝠/史莱姆 | 土拨鼠（近战小怪）/ 鬼新娘（两阶段：幻影→实体追杀）/ 蝙蝠（暗处抱头夺装备） |
| 死亡惩罚：携带物全丢 | **即死出局**：死亡掉落全部携带物散落原地，可被任何人拾取；本局观战（一队一人，无队友可救） |
| 机关解谜：集齐青铜镜启动升降梯、连弩、假门 | 集齐三面铜镜开启密室（高价值房）、连弩陷阱甬道、刺刀试假门 |
| 腰包/扩展背包容量管理 | 背包 6 格 + 腰包 2 格（贵重品专用），装备解锁扩容 |
| 多模式（摸金/无尽/惊魂） | 只做摸金撤离（核心），其余后期再议 |

PvP 保留：四名玩家即四支队伍，同图各自摸金，允许互相攻击、截胡掉落物与提交点——这是在原作合作玩法之上叠加的对抗层。

已定的四项基调（2026-09-26 确认）：
1. **即死规则**：被怪物或玩家打死即出局，掉落全部携带物散落原地（可被拾取），本局观战——一队一人，无队友可救
2. **经济隔离**：摸金收益只解锁游戏内装备图鉴，不接站内积分
3. **恐怖尺度 = 氛围压迫**：黑暗、音效、被追击的紧张感，不做贴脸惊吓（用户群体是初中生）
4. **开局人数**：至少 2 名真人，不足席位自动补 AI 摸金客（各自独立一队）

## 二、单局流程

1. **准备**（大厅）：配 4 件装备 → 开局
2. **进入**：四人从四个不同入口甬道进墓，出生 30 秒保护
3. **搜集**：黑暗中探墓，文物按价值分四档（白/绿/紫/金），捡拾入包
4. **威胁升级**：拿到紫色以上文物 → 全图危险度提升；金色 → 怪物狂暴潮
5. **提交**：回陵外马车提交（提交后安全，但不能反悔）
6. **撤离**：提交总额达标 → 车夫打灯笼 → 60 秒倒计时全员上车 → 结算
7. **结算**：按提交金额分红 + 击杀怪物资深加成；死亡未撤离者本局颗粒无收

单局 12 分钟（+撤离 1 分钟），目标节奏：5 分钟浅层搜索 → 3 分钟深入 → 3 分钟回撤 → 1 分钟缓冲。

## 三、地图（96×72 tile）

- 唯一大墓「九层妖楼」，手搭固定图，不做程序化生成、不做编辑器
- 分区：
  - 四角入口甬道（各自通向墓道环线，开局互不可见）
  - 甬道环线：嗜血蝠群出没 + 连弩陷阱段 + 假门×3
  - 偏殿 ×4（对称布局保证四队资源公平，绿档文物为主）
  - 主墓室（中央，鬼新娘领地，紫档文物）
  - 棺椁房 ×2（金档文物 + 铜镜，鬼新娘幻影出现地之一）
  - 铜镜密室（集齐三面铜镜开启，金档 + 「墓中之王」）
  - 陵外：马车（提交/撤离点）+ 安全区（怪物不进）

## 四、装备

玩家不再区分身份（先不做角色技能），打法差异全部来自装备组合。

**装备（每局带 4 件，收益解锁图鉴）**：
| 类 | 装备 | 效果 |
|---|---|---|
| 武器 | 桃木剑 | 近战主武器，**鬼新娘幻影阶段唯一有效的武器** |
| 武器 | 电磁枪 | 吸附定身怪物 3 秒（冷却 15 秒），对鬼新娘幻影无效 |
| 探测 | 洛阳铲 | 挥击辨真假门 |
| 探测 | 寻龙针 | 指针指向最近文物 |
| 防护 | 黑驴蹄子 | 使用后驱退周围怪物 5 秒 |
| 防护 | 护心镜 | 挡一次致命伤害（碎裂） |
| 辅助 | 油灯 | 光照半径，随时间耗尽（默认自带） |
| 辅助 | 医疗包 | 回血 |
| 辅助 | 扩展腰包 | +2 贵重品格 |

## 五、怪物（四套，服务端权威 AI）

**三种怪物（就这三种）**：

| 怪物 | 数值/行为 | 对策 |
|---|---|---|
| **土拨鼠** | 60 血，近身啮咬一下 20 血，墓道内游荡 | 桃木剑/电磁枪可击杀，掉落小价值回收物 |
| **鬼新娘** | **两阶段**：①幻影阶段——先后出现数次（浮现→消散），此时**只有桃木剑能伤她**，电磁枪/黑驴蹄子等一律无效，幻影阶段内将其击杀则本局除名；②若幻影阶段未被击杀，**显出实体并锁定追杀一名玩家，被追到即死** | 幻影期用桃木剑速杀，或趁幻影间歇拉开距离绕行 |
| **蝙蝠** | 藏在暗处不动，玩家靠近时扑出**抱住头部**：玩家携带道具**全部掉落**，之后每 2 秒扣 10 血 | 被抱时先挣脱/被扣血到一定程度自动挣脱（掉落物含武器），**捡回武器后将其击杀**；护心镜可挡扑击 |

- 每局按点位表刷：土拨鼠 2~3 只、鬼新娘 1 只（主墓室）、蝙蝠 2~3 只（暗处点位）
- 金色文物触发事件性增援（追加土拨鼠/蝙蝠）
- 击杀掉落「墓中异宝」（紫/金档），打怪是赚钱手段之一
- 三怪均为服务端权威 AI（状态机：巡逻/索敌/追击/返回），客户端只做表现

## 六、分阶段规划

### 阶段 0：素材底座与权限开关

**目标**：素材到位、渲染骨架能跑、入口只对超管可见。

1. 素材清单与获取（16×16 像素风）：
   - 通用 tile（墙/地/门/假门/楼梯/陷阱）：Kenney（CC0）/ OpenGameArt / itch.io，逐个记录许可证
   - 中式件（棺椁/灯笼/鼎/碑/铜镜/陶俑/马车）：现成 CC0 凑不齐，自绘补齐
   - 角色 4 色（同帧异色区分玩家）、怪物三套（土拨鼠/鬼新娘含幻影与实体两态/蝙蝠含抱头姿态，移动/攻击帧各 4~6 帧）
   - 文物 12 种（四档各 3 种）、装备图标 10 个、UI 骨架图标
   - 音效延后到阶段 4
2. Canvas 渲染骨架：相机跟随、tilemap、60fps 主循环、integer scaling
3. 权限开关：`site_config` 一行开关 + 路由守卫（非超管 404）；导航入口 PC/移动两套都仅超管渲染

**交付**：超管可进临时测试图走动；他人 404、导航无入口。
**验收**：手机+PC 两端 OK，权限双保险确认。

### 阶段 1：单机核心循环（摸金闭环）

**目标**：一个人完整玩一局，原作核心机制全部落地。

1. 完整大墓地图（手搭 JSON + 碰撞层）
2. 移动/碰撞/蹲行（键盘 + 手机虚拟摇杆）
3. 光照：黑暗遮罩 + 油灯光圈 + 火把；油灯耗尽机制
4. 土拨鼠（最简 AI：巡逻+近身啮咬 20 血/次，60 血可被击杀）——威胁感先行，阶段 3 再上鬼新娘与蝙蝠
5. 文物四档散布 + 背包 6 格/腰包 2 格
6. 金额目标 + 马车提交 + 60 秒撤离倒计时 + 结算页
7. 局外：配装 4 件（装备效果先实装：桃木剑/洛阳铲/黑驴蹄子/油灯/医疗包/寻龙针）
8. 数据表 `guling_stats` / `guling_runs`（收益累计 → 解锁装备图鉴）

**交付**：超管单人完整一局（配装→进墓→打土拨鼠→达标→撤离→结算→解锁）。
**验收**：单局 12 分钟节奏成立，金额不达标失败线明确。

### 阶段 2：四人同局联机

**目标**：四人同图互相可见，同步骨架定型。

1. 开局：大厅一键开局，**至少 2 名真人，不足的席位自动补 AI 摸金客**（各自独立一队，会移动、拾取、躲怪、逃向马车；联机框架内跑，与玩家同一同步协议），四入口随机分配
2. 同步：SocketIO 房间广播 10Hz + 客户端插值；移动本地算，服务端只校验关键事件
3. 土拨鼠状态同步（服务端权威怪物同步骨架，阶段 3 复用）
4. 断线：60 秒重连回原局，超时角色倒地掉落
5. 提交/撤离的多人时序（谁的车、结算归属）

**交付**：4 窗口同图各自摸金、互见、安全提交撤离。
**验收**：2G 服务器单房 ≤15Hz、同时 2 局上限，负载可控。

### 阶段 3：全套怪物 + PvP

**目标**：四套怪物 + 玩家互斗，双威胁成型。

1. 鬼新娘两阶段（幻影仅桃木剑可伤→实体锁定追杀即死）与蝙蝠（抱头夺装备+每 2 秒 10 血）上线
2. 动态危险：紫/金文物触发全图增援与狂暴
3. PvP：桃木剑近战 + 电磁枪（可定怪也可定人 2 秒），攻击服务端校验
4. 即死出局：死亡掉落全部携带物，任何幸存者可拾取；死者本局观战
5. 击杀结算：怪物异宝掉落 + 击杀玩家分一半战利品
6. 机关：连弩陷阱段、假门（洛阳铲辨真假）、铜镜密室（集齐三面开启）

**交付**：完整威胁模型下的一局（怪物+玩家+机关）。
**验收**：伪造攻击无效；机关与怪物在联机下稳定；狂暴潮触发正确。

### 阶段 4：氛围打磨与开放

1. 音效：脚步回声、心跳（低血量/怪物近身）、铜铃、棺椁开启、鬼新娘吟唱、蝙蝠振翅
2. 氛围事件：烛火转青、棺盖自开（不新增威胁实体）
3. 经济隔离维持：摸金收益只解锁装备图鉴，不接站内积分（后续做活动再议）
4. 更新日志、games.html 卡片入口、权限开关放开全量
5. 数值平衡：按超管试玩数据调文物价值表/怪物强度

**交付**：正式版全量。
**验收**：非超管可玩、积分落账、稳定运行一周。

## 七、明确不做的（防蔓延）

- 程序化地图生成、地图编辑器（上次删掉的直接原因）
- 多楼层、无尽模式、惊魂逃生模式（只做摸金撤离）
- 语音、局内文字聊天
- 救援/搬运机制（一队一人，即死规则下无意义）
- 怪物巢穴/波次刷新系统（只做点位表+事件增援）
- 时装/皮肤系统（图鉴解锁只给装备）

## 八、技术要点

| 项 | 决策 |
|---|---|
| 渲染 | Canvas 2D，16×16 tile，integer scaling，60fps |
| 同步 | SocketIO 房间 10Hz + 客户端插值；移动本地算；关键事件服务端校验 |
| 权威 | 服务端管：拾取/提交/攻击/撤离/怪物 AI/结算 |
| 地图 | 服务端单份 JSON，客户端缓存 |
| 表 | `guling_rooms` / `guling_stats` / `guling_runs`（init_db 手动跑） |
| 服务器 | 2G 内存：单房 tick ≤15Hz、同时 2 局上限、超限排队 |
| 版本 | 阶段 0 落地 → v1.9.0 |

## 九、第一刀

阶段 0 一把梭：素材清单落 docs、渲染骨架 + 临时测试图 + 超管开关 + 两套导航入口。
阶段 1 起每个子项都保持"随时可玩"——做完碰撞就能走，做完光照就能怕，做完土拨鼠就会死。
