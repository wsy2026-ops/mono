# 附：轮播专用版（首页那个位置）

## 为什么需要单独一版

首页轮播实际只显示 **583 × 315 px**（实测，见下表），缩放系数 **0.228**：

| 海报上的字号（2560 宽） | 轮播里实际显示 | 效果 |
|---|---|---|
| 120 px | 27.4 px | ✓ 很清楚 |
| 100 px | 22.8 px | ✓ 清楚 |
| 60 px | 13.7 px | ✓ 勉强看清 |
| 50 px | 11.4 px | ⚠️ 临界 |
| **36 px** | **8.2 px** | ✗ **看不清** |
| **20 px** | **4.6 px** | ✗ **完全糊掉** |

⚠️ **结论：给轮播用的图，字最小别小于 55px（按 2560 宽算）** ✗
主海报里的「参与步骤 28–34px」和「规则小字 20–24px」放到轮播里必然糊 ✗

## 轮播版原则

**砍掉细节，只留钩子。** 轮播是广告位，职责是让人「想点」，不是把规则讲完 ✓
细则都在活动页里，点进去看 ✓

**保留**：主标题 + 核心金额 + 三个阶梯金额
**砍掉**：参与步骤、规则小字、活动时间（这些进页面看）
